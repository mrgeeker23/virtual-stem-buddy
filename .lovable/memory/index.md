# Project Memory

## Core
Virtual Stem Player: Offline prototype for interacting with song stems via hand-gestures.
Brand color #00A8F0 (HSL 197, 100%, 47%), active states use cyan-blue glow (`rgba(0, 168, 240)`).
Use Bun package manager (`bun run dev`).
No Lovable branding or badge. Custom title "Virtual Stem Player". Logo: src/assets/logo.jpg
All audio must be MP3 in `public/audio/`.
